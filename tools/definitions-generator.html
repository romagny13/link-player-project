LinkPlayer · definitions generator

Paste the HTML of a YouTube playlist page or an Ok.ru page (.portlet): the links and the definitions (arrays of { videoId, title, channel, thumbnail, duration }) are generated hardcoded, without YouTube Data API.

1 Source

YouTube loads the playlist in batches: scroll through the entire list before copying the HTML, otherwise videos will be missing.

2 Selection

Playlist mode: the panel relies on the actual playlist index, so the selection is the whole playlist (filter, sort and selection are disabled). For a custom selection use the "list of videos" mode.

3 Code

Long list: the link URL gets very long. The playlist mode avoids it.
