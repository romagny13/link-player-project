1 · Link only : tout est défini sur les data-link

Aucune définition en code. Une seule zone cible (player-link) pour tous les liens ; une zone d'infos commune en dessous, alimentée par afterNavigate. Chaque lien a une data-key distincte (la clé par défaut est l'id de la vidéo / liste / playlist : deux liens vers la même vidéo partageraient la même info).

1. YouTube

a. Vidéo seule

  • Minimum : Maldives (minimum)
  • Autoplay au clic + start dans l'URL (t=) : Bahamas, autoplay + start 45m12s
  • Start dans data-start au format 1h20m3s (prioritaire sur l'URL) : Maldives, start 1h20m3s
  • Avec infos (title, description, channel, channelUrl, thumbnail, duration, extra) + data-show-on-init : Maldives, avec infos (showOnInit)

b. Liste de vidéos (watch_videos?video_ids=)

  • Avec video ids : Liste de 2 vidéos
  • Avec video ids et un index > 1 (démarre sur la 2e) : Liste, index=1
  • Avec autoplay : Liste, autoplay au clic
  • Avec infos par vidéo (data-videos) + extra : Liste, avec infos

c. Playlist (list=)

  • Avec playlistId et videoId (1re vidéo) : Playlist, 1re vidéo
  • Avec playlistId et videoId ne correspondant pas à la 1re vidéo : Playlist, départ sur la 2e
  • Avec infos des vidéos + extra : Playlist, avec infos

Le start d'une vidéo à l'intérieur d'une liste est lu par le parser mais pas appliqué par YouTubeView (chargement avec startSeconds = 0). L'id PLYALQE76y6LQ semble tronqué (une vraie playlist fait 34 caractères).

4 · YouTube Data API : infos par défaut, puis infos chargées

Montre deux états de la même info : (1) les infos par défaut (données sur le lien ou en définition, puis fallbackTitle) ; (2) les infos chargées via l'API (événement change avec reason = "meta"). Ordre de priorité du resolver : valeurs déclarées > API > fallback. Une valeur déjà déclarée n'est pas écrasée : l'API complète les champs vides. Sans clé (voir en haut de page), seul le fallback s'applique.

6 · Code only : définitions + méthodes de navigation

Aucun lien dans le HTML. autoScan: false, puis scan() à la main ; la première définition a showOnInit: true. Les boutons sont générés depuis region.infos et appellent region.navigate(key, {autoplay}).

7 · Un LinkPlayer global et un LinkPlayer scopé (sans conflit)

Le global (sans scope) : infobulle activée, "toggle". Le scopé (#zone-scoped) : tooltip: false, "skip". Un élément déjà pris en charge (data-lp) est ignoré par l'autre : les scopés sont créés avant le global.

8 · Boutons de navigation et comportements

Chaque barre de boutons est branchée sur la région : back / forward, info précédente / suivante, item précédent / suivant (liste ou playlist), afficher / masquer. Les boutons sont grisés selon canGoBack, canGoForward, canGoPreviousInfo, canGoNextInfo, canGoPreviousItem, canGoNextItem.

  • currentBehavior (clic sur le lien déjà affiché) : "toggle" masque/ré-affiche, "skip" ne fait rien, "playPause" bascule lecture/pause.
  • boundaryBehavior (aux extrémités de nextInfo() / previousInfo()) : "stop" s'arrête, "loop" boucle (il faut au moins 2 infos).
  • useStorage et showOnInit : zone « toggle » avec useStorage: true (recharge la page : le dernier lien est restauré et prime sur showOnInit).

9 · Format (short) et démarrage muet

FormatBehavior pose data-lp-format sur le conteneur : cliquez d'un lien à l'autre, la zone change de forme. Le format vient de l'URL (/shorts/ID → portrait) ou de data-format (portrait, 9/16, square, landscape).

a. Format et mute au clic

  • Short détecté dans l'URL : Short (portrait détecté)
  • Short, autoplay + muet (data-autoplay="click" data-mute) : Short, autoplay muet
  • Format forcé sur une vidéo ordinaire : Maldives en 9/16 (forcé) | Maldives en carré
  • YouTube, autoplay + muet : Maldives, autoplay muet
  • OK.ru, autoplay + muet (seulement si le relais applique mute) : OK.ru, autoplay muet
  • Contrôle, autoplay avec le son : Tahiti, autoplay avec le son

b. Au chargement de la page, sans geste de l'utilisateur

data-show-on-init data-autoplay data-mute : seul le démarrage muet est autorisé par les navigateurs. Le bouton active le son.
