LinkPlayer — tout déclaré en code

  • YouTube : vidéo seule, playlist par video ids, playlist par playlist id (contenu déclaré).
  • Ok.ru : vidéo seule, playlist par ids + titres, avec saisons.
  • Panel YouTube : fermé (bouton en bas à gauche). Panel Ok.ru : ouvert (bouton en haut à droite si fermé).
